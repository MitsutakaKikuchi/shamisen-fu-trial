# 三味線譜エディタ — 体験版

長唄三味線の譜面（縦譜＝縦書きの数字譜）をブラウザで書いて、印刷できるソフトの体験版です。インストール不要、登録不要。

**開く → https://MitsutakaKikuchi.github.io/shamisen-fu-trial/**

- 楽譜のデータは**お使いの端末にだけ**保存されます（こちらのサーバには送りません）。
- ファイルは `.sfu`（JSON）で保存・受け渡しができます。
- iPad でも使えます。外付けキーボードをつなぐと、数字キーでそのまま打てます。Safari の共有 →「ホーム画面に追加」で、ネットに繋がなくても開けます。

## 体験版（Free）でできること
記譜・編集・ファイル保存は無制限。縦譜は 1 頁まで表示・印刷できます（透かし入り）。替手は**表示のみ**。再生・横譜（三本線のタブ譜）の表示・見た目の設定は Pro でお使いいただけます。

Pro はライセンスキーを貼るだけで開きます。お申し込みのご案内は準備中です。

## 使い方のさわり
- 数字 `1`〜`7` で音を置く。`Q` `W` `E` で四分・八分・十六分。`0` 休符、`Space` 伸ばす
- `K` スクイ、`H` ハジキ、`.` 甲、`,` 乙、`+` `-` 半音
- 右上の `？` に操作ガイド（iPad ＋ キーボードの章もあります）
