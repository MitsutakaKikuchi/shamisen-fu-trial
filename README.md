# 研精会譜・文化譜エディタ — 体験版

長唄三味線の譜面（研精会譜＝縦譜）をブラウザで書いて、印刷できるソフトの体験版です。インストール不要、登録不要。

**開く → https://MitsutakaKikuchi.github.io/shamisen-fu-trial/**

- 楽譜のデータは、お使いのパソコン（ファイルと「保存した曲」）にだけ保存されます。サーバには送られません。
- 体験版（Free）でできること: 記譜・編集・ファイル保存は無制限。研精会譜は 1 頁まで表示・印刷（透かし付き）。本手のみ。
- Pro（月 980 円）にすると: 頁数の制限なし、透かし無しの印刷、再生、替手、表示設定、文化譜の表示・印刷、優先サポート。
  お申し込み後に届くライセンスキーを、アプリ右上の「Free」→「ライセンスキー」に貼り付けてください。

`samples/` に見本の譜（`.sfu`）があります。アプリの「開く」から読み込めます。

このリポジトリには配布用のファイル（`index.html`）だけを置いています。ソースコードは別の非公開リポジトリで管理しています。
